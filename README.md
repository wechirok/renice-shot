# Renice Shot

A fork of [Fabrishot](https://github.com/ramidzkh/fabrishot), maintained for mc versions not yet supported upstream and intended as a fallback when upstream updates are delayed.

[Mod Menu](https://modrinth.com/mod/modmenu) and [Cloth Config](https://github.com/shedaniel/cloth-config) are optional and provide an in-game configuration screen.
